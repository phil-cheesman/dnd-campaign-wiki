# Spelling conflicts — Jon vs. Jon

During Phase B1 ingest of Jon's authoritative worldbuilding docs (`sources/dm-docs/`), several entities are spelled **inconsistently within Jon's own documents** (a doc title disagrees with its own body, or one doc disagrees with another). For each, we picked a canonical spelling, demoted the rest to glossary aliases, and logged it here so Jon can confirm. None of these are play-notes mishearings (those were resolved by the pre-approved promotion decision) — these are genuine author-vs-author conflicts.

> **Jon's review (2026):** answers recorded inline below. Two overrides — **Kirkenwall→Kierkenwall** and **Tarleaf→Tarlif** — have been applied as renames across canon.

Where a pre-approved spelling promotion already applied (e.g. Sultray → Surtree, Mandalonia → Maadolonia, Paratha → Parathia), only the residual Jon-vs-Jon variant is logged below.

- **Kirkenwall** and **Tarleaf** were deliberately **NOT** renamed despite Jon's prose using Kierken-/Tarlif, because both are entrenched in play and (for Kirkenwall) backed by a map asset. If Jon prefers his prose spelling to win for these too, flag it and we will run the rename + glossary flip.
- **Grillers** had its glossary canonical flipped but no dossier file existed to `git mv`; the Write phase will create `canon/locations/grillers.md`.
- All demoted spellings were preserved as aliases — nothing was deleted.
