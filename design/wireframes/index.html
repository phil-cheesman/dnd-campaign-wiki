Alambor Wiki — Wireframe Gallery

Eight design directions for an article page, all rendering the same content (the Mally Grisham dossier) so you're comparing pure aesthetics. Open each in a browser tab and flip between them. Concepts 06–08 are modern variants spun off the Modern Codex (02).

CONCEPT 01

The Illuminated Folio

A scribe's manuscript: parchment, blackletter masthead, red-ink rubrics, illuminated drop caps, double-ruled page frame, numbered chapters, wax seal.

CONCEPT 02

The Modern Codex

Clean, contemporary docs-site feel (Notion/Stripe-adjacent) with quiet fantasy accents: warm off-white, garamond display type, gold hairlines, sticky sidebars, ⌘K search.

MinimalModernLight
CONCEPT 03

Torchlit Depths

Dark-mode dungeon: carved-stone headers, amber torch-glow accents, a 5e-statblock-style infobox, quest-log open threads, "depth" breadcrumbs.

CONCEPT 04

The Cartographer's Table

A nautical chart: compass-rose cartouche, dashed-route breadcrumbs, numbered map markers as headings, a LEGEND infobox, voyage-log table, customs stamps.

CONCEPT 05

The Rubricated Press

Fine-press editorial: one big garamond column with scholarly marginalia, red rubrication (pilcrows, drop cap, pull quote), hairline rules — modern typographic, medieval ink.

EditorialTypographicMarginalia
CONCEPT 06

The Midnight Codex

The Modern Codex flipped to dark mode (Linear/Vercel-adjacent): warm near-black surfaces, the same garamond display and three-column shell, gold accents that now glow.

CONCEPT 07

The Swiss Chronicle

International-style broadsheet: hard grid with visible rules, uppercase grotesque headline, mono small-cap labels, numbered sections, square corners, one red accent.

The Quiet Archive

App-shaped (Notion-adjacent): workspace sidebar, breadcrumb chips, tabs with counts, a Properties panel as the infobox, soft-shadow section cards, sage-green accent.

The Journey (Map + Timeline)

Phase 3 mockup in the Modern Codex skin: an SVG world map with the party's full route, a draggable E00–E161 scrubber with arc bands, planar insets for Avernus/Shadowfell, and a story card per stop. Real data from the canon timeline.
